# 钉钉 AI 听记自动检查系统 - 完整部署指南

## 📋 项目概述

自动化系统，用于每天检查32个业务单元的钉钉AI听记执行情况，生成详细日报。

## 🚀 快速开始

### 第一步：环境检查

```bash
cd ~/
./check_env.sh
```

### 第二步：启动 Chrome 远程调试

```bash
./start_chrome_debug.sh
```

启动后：
1. 登录钉钉文档
2. 打开目标表格：https://alidocs.dingtalk.com/i/nodes/93NwLYZXWygvM0mMuk4O7vj7JkyEqBQm
3. 保持浏览器开启

### 第三步：安装定时任务

```bash
./install_schedule.sh
```

### 完成！

系统将在每天上午10点自动运行，报告保存在 `~/daily_reports/`

## 🔧 定时任务管理

### 查看任务状态
```bash
launchctl list | grep dingtalk
```

### 查看任务详情
```bash
launchctl print gui/$(id -u)/com.dingtalk.dailycheck
```

### 手动触发（测试）
```bash
./run_daily_check.sh
```

### 停止任务
```bash
launchctl unload ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
```

### 重新启动任务
```bash
launchctl unload ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
launchctl load ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
```

### 修改执行时间

编辑 `~/Library/LaunchAgents/com.dingtalk.dailycheck.plist`：

```xml
<key>StartCalendarInterval</key>
<dict>
    <key>Hour</key>
    <integer>10</integer>  <!-- 修改小时 (0-23) -->
    <key>Minute</key>
    <integer>0</integer>   <!-- 修改分钟 (0-59) -->
</dict>
```

修改后重新加载任务。

## 🛠 高级配置

### Chrome 开机自启动（推荐）

```bash
# 复制配置文件
cp ~/com.chrome.debugmode.plist ~/Library/LaunchAgents/

# 加载任务
launchctl load ~/Library/LaunchAgents/com.chrome.debugmode.plist

# 验证
launchctl list | grep chrome
```

配置后，Chrome 将在登录时自动以远程调试模式启动。

### 多个检查时间

复制并修改 plist 文件以添加多个时间点：

```bash
# 复制配置
cp ~/com.dingtalk.dailycheck.plist ~/com.dingtalk.dailycheck.afternoon.plist

# 编辑新文件，修改：
# - Label 为 com.dingtalk.dailycheck.afternoon
# - Hour 为 14 (下午2点)

# 加载新任务
cp ~/com.dingtalk.dailycheck.afternoon.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.dingtalk.dailycheck.afternoon.plist
```

## 🐛 故障排除

### 问题1：Chrome 连接失败

**症状**：日志显示 "无法连接到Chrome"

**解决方案**：
```bash
# 检查端口是否开放
lsof -i :9222

# 如果没有输出，启动Chrome
./start_chrome_debug.sh
```

### 问题2：找不到链接

**症状**：所有单元都显示 "未找到任何工作表链接"

**可能原因**：
1. Chrome 未登录钉钉
2. 未打开正确的表格页面
3. 网络问题

**解决方案**：
1. 在Chrome中手动访问表格页面
2. 确保已登录
3. 保持页面开启，重新运行

### 问题3：Python 模块未找到

**症状**：ImportError: No module named 'playwright'

**解决方案**：
```bash
cd ~/
source .venv/bin/activate
pip install playwright
playwright install chromium
```

### 问题4：权限错误

**症状**：Permission denied

**解决方案**：
```bash
# 修复脚本权限
chmod +x ~/run_daily_check.sh
chmod +x ~/start_chrome_debug.sh
chmod +x ~/install_schedule.sh
chmod +x ~/check_env.sh

# 修复目录权限
chmod 755 ~/daily_reports
```

### 问题5：定时任务不执行

**检查步骤**：

1. 验证任务已加载
```bash
launchctl list | grep dingtalk
```

2. 查看任务详情
```bash
launchctl print gui/$(id -u)/com.dingtalk.dailycheck
```

3. 检查日志
```bash
tail -50 ~/daily_check_stderr.log
```

4. 手动测试
```bash
./run_daily_check.sh
```
