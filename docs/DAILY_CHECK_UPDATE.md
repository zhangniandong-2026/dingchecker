## 使用方法

### 运行检查（检查所有33个单元）

```bash
# 检查今天
cd ~/dingtalk_checker
python3 scripts/daily_check.py

# 检查指定日期
python3 scripts/daily_check.py 2026-03-02
```

### 预计执行时间

- 单个业务单元：约 15-30 秒
- 33个业务单元：约 **8-16 分钟**

### 报告输出

报告保存在：`~/dingtalk_checker/daily_reports/report_YYYY-MM-DD.txt`

包含：
- 统计摘要
- 各业务单元详情
- AI智能分析

### 注意事项

1. **执行前确保Chrome调试模式运行中**：
   ```bash
   bash ~/dingtalk_checker/chrome/start_chrome_debug.sh
   ```

2. **建议在网络稳定时执行**：
   - 33个单元需要多次页面切换
   - 网络不稳定可能导致部分单元提取失败

3. **如果只想检查部分单元**：
   编辑 `daily_check.py` 第16-49行的 `ALL_SHEETS` 列表，注释掉不需要的单元：

   ```python
   ALL_SHEETS = [
       "安徽组",
       "山东组",
       # "浙江组",  # 注释掉不检查
       ...
   ]
   ```

## 故障排除

### 问题：某些业务单元无法访问

**可能原因**：
- 权限问题
- 工作表名称变更
- 网络超时

**解决方法**：
- 检查是否有该工作表的访问权限
- 确认工作表名称是否正确
- 重新运行脚本

### 问题：执行时间过长

**建议**：
- 分批次检查（修改ALL_SHEETS列表）
- 在网络状况好的时段运行
- 增加脚本超时时间（修改timeout参数）

## 与skill集成

skill现在也支持33个业务单元的检查：

```bash
# 通过skill运行（自动调用daily_check.py）
/ding-check status  # 查看系统状态
```

## 性能优化建议

如果经常只需要检查部分业务单元，可以创建多个配置文件：

```bash
# 创建重点单元配置
cp scripts/daily_check.py scripts/daily_check_key.py

# 编辑 daily_check_key.py，只保留6个重点单元
```

然后分别调用：
```bash
# 检查所有单元
python3 scripts/daily_check.py

# 只检查重点单元（快速）
python3 scripts/daily_check_key.py
```
