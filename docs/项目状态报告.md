## 🚀 使用指南

### 查看今天的报告
```bash
cat ~/dingtalk_checker/daily_reports/report_$(date +%Y-%m-%d).txt
```

### 手动运行检查
```bash
cd ~/dingtalk_checker
source ~/.zshrc           # 加载代理配置
source .venv/bin/activate # 激活虚拟环境
python3 scripts/daily_check.py
```

### 测试单个业务单元
```bash
cd ~/dingtalk_checker
source .venv/bin/activate
python3 tests/test_single.py "业务单元名" "2026-03-02"
```

## ⚙️ 配置说明

### 环境变量（~/.zshrc）
```bash
# Gemini API
export GEMINI_API_KEY="YOUR_API_KEY_HERE"

# 代理配置（用于访问Google服务）
export HTTP_PROXY="http://127.0.0.1:7890"
export HTTPS_PROXY="http://127.0.0.1:7890"
export ALL_PROXY="socks5://127.0.0.1:7890"
export NO_PROXY="localhost,127.0.0.1,::1"

# gRPC 代理（Gemini API 必需）
export GRPC_PROXY="http://127.0.0.1:7890"
export grpc_proxy="http://127.0.0.1:7890"
```

**重要**: GRPC_PROXY 是必需的，因为 Gemini API 使用 gRPC 协议。

### 定时任务
- 配置文件: `~/Library/LaunchAgents/com.dingtalk.dailycheck.plist`
- 运行时间: 每天10:00
- 启动脚本: `scripts/run_daily_check.sh`

### Chrome远程调试
- 启动脚本: `chrome/start_chrome_debug.sh`
- 端口: 9222
- 需手动启动或设置开机自启
