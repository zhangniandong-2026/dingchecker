# AI分析功能配置说明

## ✅ 已完成的功能

1. **AI分析模块** - 使用Google Gemini Pro分析会议内容
2. **自动分析** - 每次运行daily_check.py后自动进行AI分析
3. **报告整合** - AI分析结果自动追加到每日报告末尾

## 📋 分析内容包括

1. **各业务单元工作摘要** - 提炼核心工作内容
2. **横向对比与优秀实践** - 识别值得学习的亮点
3. **改进建议** - 给出可操作的改进方向

## 🔧 配置步骤

### 1. 获取Gemini API密钥

访问：https://aistudio.google.com/app/apikey
- 登录Google账号
- 点击"Get API key"
- 创建新密钥或使用现有密钥

### 2. 配置环境变量

**临时配置（当前终端会话有效）：**
```bash
export GEMINI_API_KEY='your-api-key-here'
```

**永久配置（推荐）：**
```bash
# 编辑bash配置文件
nano ~/.zshrc  # 如果使用zsh
# 或
nano ~/.bash_profile  # 如果使用bash

# 添加以下行：
export GEMINI_API_KEY='your-api-key-here'

# 保存后重新加载
source ~/.zshrc
# 或
source ~/.bash_profile
```

### 3. 验证配置

```bash
echo $GEMINI_API_KEY
```

应该显示您的API密钥（不为空）

## 🚀 使用方法

配置完成后，正常运行脚本即可：

```bash
# 自动使用当天日期
python3 daily_check.py

# 或指定日期
python3 daily_check.py 2026-03-02
```

报告末尾会追加类似以下内容：

```

AI 智能分析
================================================================================

一、各业务单元工作摘要
【能源组】
- 主要工作：客户交流（石化明科、海牛项目）、授权材料准备、客户拜访计划
```

## ⚠️ 注意事项

1. **API费用**：Gemini Pro有免费额度，但超出后会收费
2. **网络要求**：需要能访问Google服务
3. **分析时间**：每次分析大约需要5-15秒
4. **隐私保护**：会议内容会发送到Google进行分析

## 🔍 故障排查

### 问题1：提示"未配置GEMINI_API_KEY"
**解决**：按照步骤2配置环境变量

### 问题2：提示"Google Gemini未安装"
**解决**：
```bash
source .venv/bin/activate
pip install google-genai
```

### 问题3：API调用失败
**可能原因**：
- API密钥无效
- 网络无法访问Google
- 超出API配额

**检查方法**：
```bash
# 测试API连接
python3 -c "from google import genai; client = genai.Client(api_key='your-key'); print('OK'); client.close()"
```
