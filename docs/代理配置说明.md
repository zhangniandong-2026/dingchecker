# 代理配置完成

## ✅ 已完成的配置

### 1. 代理环境变量配置
已添加到 `~/.zshrc`:
```bash
export HTTP_PROXY="http://127.0.0.1:7890"
export HTTPS_PROXY="http://127.0.0.1:7890"
export ALL_PROXY="socks5://127.0.0.1:7890"
export NO_PROXY="localhost,127.0.0.1,::1"

# gRPC 代理（Gemini API 需要）
export GRPC_PROXY="http://127.0.0.1:7890"
export grpc_proxy="http://127.0.0.1:7890"
```

**重要**: gRPC 代理是必需的，因为 Gemini API 使用 gRPC 协议而不是 HTTP。

### 2. Gemini API 配置
- API 密钥: 已配置在 ~/.zshrc
- 模型: gemini-2.5-flash（新版本，gemini-pro 已不可用）
- 代理: 必须配置 GRPC_PROXY 才能工作

### 2. 启动脚本已更新
`scripts/run_daily_check.sh` 现在会自动设置所有代理环境变量（包括 GRPC_PROXY）

### 3. 便捷函数
可以在终端使用以下命令：
```bash
proxy_on   # 开启代理
proxy_off  # 关闭代理
```

## 🔧 使用方法

### 手动运行（带代理）
```bash
cd ~/dingtalk_checker
source ~/.zshrc  # 加载代理配置
source .venv/bin/activate
python3 scripts/daily_check.py
```

### 测试代理是否工作
```bash
source ~/.zshrc
curl -I https://www.google.com
```

应该看到 `HTTP/1.1 200` 或 `HTTP/2 200`

### 测试Gemini API
```bash
cd ~/dingtalk_checker
source ~/.zshrc
source .venv/bin/activate
python3 -c "
from google import genai

client = genai.Client(api_key='YOUR_API_KEY_HERE')
response = client.models.generate_content(
    model='gemini-2.5-flash',
    contents='你好'
)
print(response.text)
response = model.generate_content('测试')
print('成功:', response.text)
"
```
