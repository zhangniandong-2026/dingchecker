# 新报告格式设计

## 报告结构

### 第一部分：标准早会建议（开篇）
```
================================================================================
钉钉早会最佳实践建议
================================================================================

📋 高效早会的五个关键要素：

1. 目标清晰 🎯
   - 用具体数字代替模糊表述（例如："完成3个客户拜访"而非"跟进客户"）
   - 明确提到客户名称、项目名称、具体金额
   - 设定明确的时间节点（"今天下午3点前"而非"尽快"）

2. 复盘闭环 🔄
   - 先汇报昨日计划的完成情况
   - 说明未完成事项的原因和调整方案
   - 形成"计划→执行→复盘→新计划"的完整循环

3. 主动协作 🤝
   - 明确提出需要的支持（"需要XX帮助我做YY"）
   - 团队成员主动响应（"我来负责"、"散会后对齐"）
   - 形成协作闭环，避免需求石沉大海

4. 聚焦重点 🔍
   - 避免单一议题占用过多时间（不超过30%）
   - 平衡覆盖所有重要事项
   - 深度讨论留到散会后1对1进行

5. 信息密度 📈
   - 分享具体的市场信息、客户需求、竞争情报
   - 避免客套话和无效寒暄
   - 每个人的发言都应该为团队带来新信息

⏰ 建议早会时长：15-20分钟
👥 建议参与方式：站立会议，提高效率
📝 建议记录方式：关键决策和行动项即时记录
```

### 第二部分：五维度评价说明
```
================================================================================
早会质量评价维度说明
================================================================================

本报告采用五维度评价体系，对每个业务单元的早会质量进行量化评估：

📊 评价维度：

一、目标清晰度 🎯 (1-5分)
   评价标准：
   - 5分：每个计划都有量化指标（数字、客户名、时间节点）
   - 4分：大部分计划有量化
   - 3分：部分计划有量化
   - 2分：少量计划有量化
   - 1分：全是模糊表述（"跟进"、"了解"等）

   重点关注：具体数字、客户名称、明确时间

二、复盘闭环率 🔄 (1-5分)
   评价标准：
   - 5分：完整复盘昨日所有计划
   - 4分：复盘主要计划
   - 3分：部分复盘
   - 2分：很少复盘
   - 1分：无复盘

   重点关注：计划→执行→反馈的完整闭环

三、协作敏捷度 🤝 (1-5分)
   评价标准：
   - 5分：所有求助都有即时响应
   - 4分：大部分求助有响应
   - 3分：部分求助有响应
   - 2分：响应不及时
   - 1分：无响应

   重点关注："需要支持"→"我来负责"的配对

四、问题聚焦度 🔍 (1-5分)
   评价标准：
   - 5分：议题均衡，重点突出
   - 4分：基本均衡
   - 3分：略有失衡
   - 2分：某议题占比>30%
   - 1分：严重失焦

   重点关注：时间分配的均衡性

五、信息增量 📈 (1-5分)
   评价标准：
   - 5分：信息密度高，无废话
   - 4分：信息较多
   - 3分：一般
   - 2分：信息较少
   - 1分：全是套话

   重点关注：市场信息、客户需求、竞争情报的具体性
```

## 关键变化总结

1. ✅ **开篇增加标准建议**：让用户先知道什么是好的早会
2. ✅ **移除转写内容**：不再显示原始转写文本
3. ✅ **强化评价说明**：清楚说明每个维度的评分标准
4. ✅ **结构化评分**：表格形式一目了然
5. ✅ **详细改进建议**：每个单元都有具体的、可执行的建议
6. ✅ **团队层面建议**：不只评价，还给出行动方案
