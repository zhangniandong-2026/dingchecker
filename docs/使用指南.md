## 🚀 您的日常使用

### 自动运行（推荐）

**无需任何操作！**

系统每天早上 **10:00** 会自动运行，完成以下工作：

1. 检查 6 个业务单元的早会记录
2. 提取 AI 会议纪要
3. 进行智能分析（包含各团队改进建议）
4. 生成两种格式的报告：
   - `report_YYYY-MM-DD.txt` - 文本版
   - `report_YYYY-MM-DD.pdf` - PDF 版（美化排版）

**报告位置**: `~/dingtalk_checker/daily_reports/`

### 查看今天的报告

#### 查看 PDF 报告（推荐）
```bash
open ~/dingtalk_checker/daily_reports/report_$(date +%Y-%m-%d).pdf
```

#### 查看文本报告
```bash
cat ~/dingtalk_checker/daily_reports/report_$(date +%Y-%m-%d).txt
```

#### 查看所有报告
```bash
ls -lh ~/dingtalk_checker/daily_reports/
```

### 手动运行

如果需要立即生成报告（不等到10:00）：

```bash
# 确保 Chrome 远程调试在运行
# 确保已在 Chrome 中登录钉钉并打开表格页面

bash ~/dingtalk_checker/scripts/run_daily_check.sh
```

## 👥 分享给别人使用

### 方式一：完整安装（推荐）

如果别人也想使用这个系统，需要：

#### 1. 准备工作
- macOS 系统
- 安装 Python 3
- 安装 Chrome 浏览器
- 安装 ClashX Meta（或其他代理工具）

#### 2. 复制项目文件
```bash
# 将整个项目文件夹复制给对方
cp -r ~/dingtalk_checker /path/to/destination/
```

#### 3. 配置环境变量
对方需要在自己的 `~/.zshrc` 中添加：

```bash
# Gemini API（需要对方自己申请）
export GEMINI_API_KEY="对方自己的API密钥"

# 代理配置（根据对方的代理端口）
export HTTP_PROXY="http://127.0.0.1:7890"
export HTTPS_PROXY="http://127.0.0.1:7890"
export ALL_PROXY="socks5://127.0.0.1:7890"
export NO_PROXY="localhost,127.0.0.1,::1"
export GRPC_PROXY="http://127.0.0.1:7890"
export grpc_proxy="http://127.0.0.1:7890"
```

#### 4. 安装依赖
```bash
pip3 install --user playwright beautifulsoup4 google-generativeai reportlab
```

#### 5. 配置定时任务
```bash
# 修改路径为对方的用户名
# 然后加载定时任务
launchctl load ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
```

#### 6. 修改监控的业务单元
编辑 `scripts/daily_check.py`，修改第 10-16 行：
```python
ALL_SHEETS = [
    "对方关心的业务单元1",
    "对方关心的业务单元2",
    # ... 添加更多
]
```

### 方式二：仅分享 PDF 报告（简单）

如果只是想**分享报告结果**给别人看：

```bash
# 直接发送 PDF 文件即可
~/dingtalk_checker/daily_reports/report_YYYY-MM-DD.pdf
```

PDF 报告是独立的文件，可以直接发送给任何人查看，无需任何配置。

## 📊 报告内容说明

每天的报告包含：

### 第一部分：数据统计
- 总计多少个业务单元
- 成功提取了多少个
- 无链接、无权限、错误的数量

### 第二部分：各业务单元详情
- 媒体军工组
- 交通行业组
- 政府行业一组
- 政府行业二组
- 能源组
- 央企组

每个单元显示：
- 状态（成功/无/无权限）
- 链接（如果有）
- 会议内容（如果成功提取）

### 第三部分：AI 智能分析（新页面）
1. **各业务单元工作摘要** - 每个单元的核心工作总结
2. **横向对比与优秀实践** - 值得学习的亮点（带✨标记）
3. **各业务单元改进建议** - 每个团队的专属建议
4. **整体改进建议** - 适用于所有团队的通用建议

## 📞 常见问题

### Q1: 报告中没有 AI 分析？
**A**: 检查：
- ClashX Meta 是否运行
- GEMINI_API_KEY 是否配置
- 查看日志：`tail -50 ~/dingtalk_checker/logs/daily_check.log`

### Q2: PDF 显示方块？
**A**: 已修复！新版本使用系统中文字体（STHeiti），完美支持中文。

### Q3: 定时任务没有运行？
**A**:
```bash
# 检查定时任务状态
launchctl list | grep dingtalk

# 重新加载
launchctl unload ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
launchctl load ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
```

### Q4: Chrome 连接失败？
**A**:
```bash
# 启动 Chrome 远程调试
bash ~/dingtalk_checker/chrome/start_chrome_debug.sh

# 在打开的 Chrome 中登录钉钉并打开表格页面
```
