# 钉钉自动推送功能使用指南

## 功能说明

每天早上9:30自动将早会分析报告推送到钉钉群。

---

## 快速开始

### 第一步：运行安装脚本

```bash
cd /Users/zhangniandong/repos/dingchecker
bash scripts/install_auto_push.sh
```

安装脚本会自动完成：
- ✅ 检查Python依赖
- ✅ 创建配置文件
- ✅ 设置脚本权限
- ✅ 创建日志目录
- ✅ 配置定时任务（可选）

### 第二步：配置钉钉机器人

#### 2.1 在钉钉群中添加机器人

1. 打开要接收报告的钉钉群
2. 点击 **群设置** → **智能群助手** → **添加机器人**
3. 选择 **「自定义」** 机器人
4. 设置机器人信息：
   - 名称：早会报告助手
   - 安全设置：**加签**（推荐）
   - 或选择：**自定义关键词**（填写"早会"）
5. 复制以下信息：
   - ✅ **Webhook URL**（必需）
   - ✅ **加签密钥（secret）**（如果选择了加签）

#### 2.2 编辑配置文件

```bash
vim /Users/zhangniandong/repos/dingchecker/config/dingtalk_webhook.json
```

修改以下字段：

```json
{
  "webhook_url": "https://oapi.dingtalk.com/robot/send?access_token=YOUR_TOKEN",
  "secret": "SECxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "enabled": true,
  "description": "早会报告推送目标群"
}
```

### 第三步：测试推送

#### 测试1：发送测试消息

```bash
python3 scripts/send_to_dingtalk.py \
  --webhook "你的webhook_url" \
  --secret "你的secret" \
  --test
```

**预期结果**：钉钉群收到测试消息

#### 测试2：推送真实报告

```bash
python3 scripts/send_to_dingtalk.py \
  --date 2026-04-30 \
  --webhook "你的webhook_url" \
  --secret "你的secret"
```

**预期结果**：钉钉群收到完整的早会分析报告

#### 测试3：完整工作流

```bash
bash scripts/auto_report_and_push.sh 2026-04-30
```

**预期结果**：
1. 采集数据
2. 生成报告（需要Claude）
3. 推送到钉钉

## 定时任务管理

### 使用crontab（推荐）

**查看配置**：
```bash
crontab -l
```

**编辑配置**：
```bash
crontab -e
```

**手动添加**（如果安装脚本跳过了）：
```bash
(crontab -l 2>/dev/null; echo "30 9 * * * /Users/zhangniandong/repos/dingchecker/scripts/auto_report_and_push.sh >> /Users/zhangniandong/repos/dingchecker/logs/auto_push.log 2>&1") | crontab -
```

**删除定时任务**：
```bash
crontab -e
# 删除包含 auto_report_and_push.sh 的行
```

### 使用macOS LaunchAgent

**查看状态**：
```bash
launchctl list | grep dingchecker
```

**手动触发**：
```bash
launchctl start com.dingchecker.autopush
```

**卸载**：
```bash
launchctl unload ~/Library/LaunchAgents/com.dingchecker.autopush.plist
rm ~/Library/LaunchAgents/com.dingchecker.autopush.plist
```

## 常见问题

### Q1: 推送失败，显示"invalid webhook url"

**原因**：webhook URL配置错误

**解决**：
1. 检查配置文件中的URL是否完整
2. 确认URL以 `https://oapi.dingtalk.com/robot/send?access_token=` 开头
3. 重新从钉钉机器人设置中复制URL

### Q2: 推送失败，显示"sign not match"

**原因**：加签密钥（secret）错误

**解决**：
1. 确认是否选择了"加签"安全设置
2. 重新从钉钉机器人设置中复制secret
3. 确保secret没有多余的空格或换行

### Q3: 定时任务未执行

**可能原因**：
- 电脑未开机
- crontab/LaunchAgent配置错误
- 脚本权限不足

**解决**：
```bash
# 检查crontab
crontab -l

# 查看系统日志
tail -f /var/log/system.log | grep cron

# 手动执行验证
bash scripts/auto_report_and_push.sh
```

### Q4: 报告未生成

**原因**：数据采集完成后，需要Claude生成报告

**解决**：
1. 确认skill.sh已执行完成
2. 检查是否有 `report_YYYY-MM-DD_publish.md` 文件
3. 如果没有，需要先运行Claude生成报告

### Q5: 消息被限流

**原因**：钉钉机器人有频率限制（每分钟最多20条）

**解决**：
- 正常使用不会触发限制
- 如果测试频繁，等待1分钟后重试

## 钉钉Markdown支持

钉钉群机器人支持的Markdown语法：

✅ 支持：
- 标题（#）
- 粗体（**text**）
- 斜体（*text*）
- 链接（[text](url)）
- 引用（>）
- 列表（-/1.）

❌ 不支持：
- 代码块（```）- 会显示为纯文本
- 表格（|）- 部分支持，显示效果有限
- 图片（![](url)）- 不支持嵌入

## 高级配置

### 推送到多个群

创建多个配置文件：

```bash
cp config/dingtalk_webhook.json config/dingtalk_webhook_group1.json
cp config/dingtalk_webhook.json config/dingtalk_webhook_group2.json
```

修改推送脚本，循环推送：

```bash
for config in config/dingtalk_webhook*.json; do
    python3 scripts/send_to_dingtalk.py \
        --date $DATE \
        --webhook $(jq -r '.webhook_url' $config) \
        --secret $(jq -r '.secret' $config)
done
```

### 推送失败告警

添加到 `auto_report_and_push.sh`：

```bash
if [ $? -ne 0 ]; then
    # 发送告警邮件或其他通知
    echo "推送失败！" | mail -s "早会报告推送失败" admin@example.com
fi
```
