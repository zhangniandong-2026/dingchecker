# 报告格式美化功能说明

## 📊 新增功能

### 1. 增强版 AI 分析

AI 分析现在包含四个部分：

#### 一、各业务单元工作摘要
- 为每个业务单元提供2-3句话的核心工作总结

#### 二、横向对比与优秀实践
- 分析对比各单元，识别3-5个值得学习的优秀做法
- 用 ✨ 标记优秀实践

#### 三、各业务单元改进建议 🆕
**为每个团队提供专属的、具体的改进建议**

例如：
- **【政府行业一组】**
  1. 细化目标分解与行动计划
  2. 深入分析并解决问题
  3. 优化内部协作流程

- **【政府行业二组】**
  1. 明确项目优先级与资源需求
  2. 风险应对方案与责任人

- **【央企组】**
  1. 增加项目风险与挑战讨论
  2. 明确项目目标与成功标准
  3. 考虑提高关键项目沟通频次

#### 四、整体改进建议 🆕
适用于所有单元的通用建议（2-3条）

### 2. PDF 报告生成 🆕

系统现在会自动生成美化的 PDF 报告，包含：
- ✅ 专业排版
- ✅ 清晰的结构层次
- ✅ 彩色标记（标题、优秀实践等）
- ✅ 适合打印和分享

## 📁 生成的文件

每次运行后会生成两个文件：

1. **文本报告**: `~/dingtalk_checker/daily_reports/report_YYYY-MM-DD.txt`
   - 完整的纯文本报告
   - 适合查看和编辑

2. **PDF报告**: `~/dingtalk_checker/daily_reports/report_YYYY-MM-DD.pdf`
   - 美化排版的PDF文件
   - 适合打印和分享

## 🚀 使用方法

### 自动生成（推荐）

系统每天 10:00 会自动运行，同时生成文本和 PDF 报告。

### 手动生成

#### 方式一：运行完整检查（推荐）
```bash
bash ~/dingtalk_checker/scripts/run_daily_check.sh
```
自动生成文本报告和 PDF 报告

#### 方式二：仅生成 PDF（从已有文本报告）
```bash
cd ~/dingtalk_checker
python3 scripts/generate_pdf_report.py daily_reports/report_2026-03-02.txt
```

## 🎨 PDF 特点

1. **专业设计**
   - A4 纸张大小
   - 合理的页边距
   - 清晰的字体和行距

2. **视觉效果**
   - 蓝色标题（#1a73e8）
   - 橙色优秀实践标记（✨）
   - 分页合理（AI分析独立页）

3. **便于阅读**
   - 层次分明
   - 重点突出
   - 易于打印

## 📝 查看报告

### 查看文本报告
```bash
cat ~/dingtalk_checker/daily_reports/report_$(date +%Y-%m-%d).txt
```

### 查看最新报告
```bash
ls -lt ~/dingtalk_checker/daily_reports/ | head -5
```

### 打开 PDF 报告
```bash
open ~/dingtalk_checker/daily_reports/report_$(date +%Y-%m-%d).pdf
```

## 🔧 自定义 PDF 样式

如果需要调整 PDF 样式，可以编辑：
```
~/dingtalk_checker/scripts/generate_pdf_report.py
```

可调整的内容：
- 字体大小
- 颜色方案
- 页边距
- 段落间距
