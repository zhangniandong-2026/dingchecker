# 钉钉 AI 听记每日自动检查 - 定时任务安装说明

## 功能说明

每天上午10点自动执行脚本，检查所有32个业务单元的AI听记执行情况，生成日报。

## 前提条件

⚠️ **重要**：定时任务执行前，必须确保 Chrome 远程调试模式已启动并保持运行。

### 启动 Chrome 远程调试模式

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir=~/chrome_debug_profile
```

启动后：
1. 在浏览器中登录钉钉文档
2. 打开目标表格页面：https://alidocs.dingtalk.com/i/nodes/93NwLYZXWygvM0mMuk4O7vj7JkyEqBQm
3. 保持浏览器窗口打开（可以最小化）

## 安装步骤

### 1. 复制 plist 文件到 LaunchAgents 目录

```bash
cp ~/com.dingtalk.dailycheck.plist ~/Library/LaunchAgents/
```

### 2. 加载定时任务

```bash
launchctl load ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
```

### 3. 验证任务已加载

```bash
launchctl list | grep dingtalk
```

应该看到类似输出：
```
-	0	com.dingtalk.dailycheck
```

## 卸载定时任务

如果需要停止或删除定时任务：

```bash
# 卸载任务
launchctl unload ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist

# 删除配置文件（可选）
rm ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
```

## 修改执行时间

如果需要修改执行时间，编辑 plist 文件中的 `StartCalendarInterval` 部分：

```xml
<key>StartCalendarInterval</key>
<dict>
    <key>Hour</key>
    <integer>10</integer>  <!-- 修改这里的小时 (0-23) -->
    <key>Minute</key>
    <integer>0</integer>   <!-- 修改这里的分钟 (0-59) -->
</dict>
```

修改后需要重新加载：
```bash
launchctl unload ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
launchctl load ~/Library/LaunchAgents/com.dingtalk.dailycheck.plist
```

## 常见问题

### 1. Chrome 远程调试未启动

**现象**：日志显示连接失败
**解决**：确保 Chrome 远程调试模式在运行，检查端口 9222 是否开放

```bash
lsof -i :9222
```

### 2. 权限问题

**现象**：任务无法执行
**解决**：检查脚本执行权限

```bash
chmod +x ~/run_daily_check.sh
```

### 3. Python 环境问题

**现象**：找不到 Python 模块
**解决**：确保虚拟环境正确安装

```bash
cd ~/
source .venv/bin/activate
pip list | grep playwright
```

### 4. 查看任务状态

```bash
# 查看任务是否在运行
launchctl list | grep dingtalk

# 查看任务详细信息
launchctl print gui/$(id -u)/com.dingtalk.dailycheck
```

## 文件说明

- `daily_check.py` - 主程序，检查所有业务单元
- `run_daily_check.sh` - 启动脚本，激活环境并运行
- `com.dingtalk.dailycheck.plist` - LaunchAgent 配置文件
- `daily_reports/` - 日报存放目录
- `daily_check.log` - 执行记录
- `daily_check_stdout.log` - 标准输出日志
- `daily_check_stderr.log` - 错误日志

## 报告格式

每天的报告包含：
- 检查日期和时间
- 32个业务单元的检查结果：
  - ✓ 成功提取（显示会议纪要摘要）
  - - 无听记链接
  - ✗ 无权限/错误
- 汇总统计

报告文件名：`report_2026-02-24.txt`

## 建议

1. **保持 Chrome 远程调试常开**：建议将 Chrome 远程调试设为开机启动
2. **定期检查日志**：每周检查一次日志，确保任务正常执行
3. **备份报告**：定期备份 daily_reports 目录
4. **网络稳定**：确保网络连接稳定，避免检查过程中断
