## 功能说明

每天自动完成：
1. 采集35个业务单元早会数据
2. 生成AI分析报告
3. 创建钉钉文档（完整报告）
4. 推送简版摘要到钉钉群（含文档链接）

### 第四步：配置定时任务

#### 方案A：crontab（推荐）

```bash
# 编辑 crontab
crontab -e

# 添加定时任务（每天10:00执行，工作日）
0 10 * * 1-5 /Users/zhangniandong/repos/dingchecker/scripts/auto_report_and_push.sh >> /Users/zhangniandong/repos/dingchecker/logs/auto_push.log 2>&1
```

**说明**：
- `0 10 * * 1-5`：每天10:00，仅工作日（周一到周五）
- 留足时间给转写（早会9:30结束 → 10:00推送）

#### 方案B：手动触发

如果不想用定时任务，每天手动运行：

```bash
bash scripts/auto_report_and_push.sh
```

## 工作流程详解

### 时间线（每个工作日）

```
09:00-09:30  各单元开早会
    ↓
09:30-09:50  钉钉AI转写
    ↓
10:00        【自动触发】采集数据
    ↓
10:01        【自动等待】等待Claude生成报告（最多5分钟）
    ↓
10:06        【自动创建】钉钉文档（完整报告）
    ↓
10:07        【自动生成】简版摘要
    ↓
10:08        【自动推送】钉钉群消息
    ↓
10:09        ✅ 管理层收到报告
```

### 步骤1：采集数据

```bash
bash skill/skill.sh collect 全部 2026-05-06
```

**输出**：`data/daily_reports/minutes_2026-05-06.json`

**关键检查**：
- dws token 是否有效
- 采集账号是否在所有早会群里
- 转写是否完成（如太早会无转写）

### 步骤2：生成报告（需要Claude）

**手动生成**（如果自动等待超时）：

在 Claude Code 中运行 `ding-check` skill，生成报告到：
```
~/.claude/Obsidian Vault/ai-output/dingtalk-minutes/report_YYYY-MM-DD.md
```

**报告特点**：
- 有 frontmatter（vault版）
- 包含详细评分和点评
- 35个单元完整数据

### 步骤3：创建钉钉文档

```bash
dws doc create \
  --name "早会分析报告 2026-05-06" \
  --workspace "lPDmr9BoD10l6Xxd" \
  --folder "R1zknDm0WR3jbR0bS2GNjLvpVBQEx5rG" \
  --markdown "报告内容（去掉frontmatter）"
```

**返回**：钉钉文档链接

### 步骤4：生成简版摘要

```bash
python3 scripts/generate_summary.py \
  --report ~/.claude/Obsidian\ Vault/ai-output/dingtalk-minutes/report_2026-05-06.md
```

**包含**：
- 统计数字
- 预警单元
- 完整排名（按评级分组）
- 激励机制
- 两个文档链接

### 步骤5：推送到群

```bash
python3 scripts/send_to_dingtalk.py \
  --date 2026-05-06 \
  --report ~/.claude/Obsidian\ Vault/ai-output/dingtalk-minutes/report_2026-05-06.md
```

## 常见问题

### Q1: 定时任务未执行

**检查**：
```bash
# 查看 crontab 配置
crontab -l

# 查看系统日志
tail -f /var/log/system.log | grep cron

# 手动执行验证
bash scripts/auto_report_and_push.sh
```

**可能原因**：
- 电脑未开机
- crontab 配置错误
- 脚本权限不足

### Q2: 报告未生成

**原因**：报告需要 Claude 生成，不是自动的

**解决**：
1. 手动运行 `ding-check` skill 生成报告
2. 或等待自动采集后，手动生成一次
3. 未来可通过 Claude API 自动化

### Q3: 权限错误（X个单元无法访问）

**原因**：采集账号不在某些单元的早会群里

**解决**：
1. 确认当前 dws 登录账号：`dws auth status`
2. 将该账号加入所有35个业务单元的早会群
3. 重新采集验证

### Q4: 推送失败

**检查**：
```bash
# 查看详细日志
cat logs/auto_push.log

# 测试推送
python3 scripts/send_to_dingtalk.py --test

# 检查配置
cat config/dingtalk_webhook.json
```

**可能原因**：
- Webhook URL 错误
- Secret 错误
- 网络问题
- 钉钉限流（每分钟20条）

### Q5: 钉钉文档创建失败

**检查**：
```bash
# 测试 dws 文档创建
dws doc create --name "测试" \
  --workspace "lPDmr9BoD10l6Xxd" \
  --folder "R1zknDm0WR3jbR0bS2GNjLvpVBQEx5rG" \
  --markdown "# 测试"

# 查看 dws 认证状态
dws auth status
```

## 高级配置

### 推送到多个群

复制配置文件：
```bash
cp config/dingtalk_webhook.json config/dingtalk_webhook_group2.json
```

修改推送脚本循环推送，或手动推送两次。

### 节假日跳过

修改 crontab，添加日期判断：
```bash
0 10 * * 1-5 /path/check_holiday.sh && /path/auto_report_and_push.sh >> ...
```

### 推送失败告警

在 `auto_report_and_push.sh` 失败时发送告警：
```bash
if [ $? -ne 0 ]; then
    # 发送告警到另一个群或邮件
    python3 scripts/send_alert.py "推送失败"
fi
```

## 脚本参数说明

### send_to_dingtalk.py

```bash
python3 scripts/send_to_dingtalk.py [选项]

选项:
  --date YYYY-MM-DD     报告日期（必需）
  --report PATH         完整报告路径（可选，默认从vault读取）
  --summary PATH        摘要文件路径（可选，自动生成）
  --webhook URL         钉钉webhook（可选，从配置读取）
  --secret SECRET       加签密钥（可选，从配置读取）
  --skip-doc            跳过创建钉钉文档（调试用）
  --test                测试模式
```

### generate_summary.py

```bash
python3 scripts/generate_summary.py [选项]

选项:
  --report PATH         完整报告路径（必需）
  --output PATH         输出文件路径（可选，默认打印到stdout）
```

### auto_report_and_push.sh

```bash
bash scripts/auto_report_and_push.sh [日期]

参数:
  日期                  YYYY-MM-DD格式，默认为昨天
```
